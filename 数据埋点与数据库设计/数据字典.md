## 1. 标记与公共字段

字段标记：`PK` 主键、`FK` 外键、`UK` 唯一、`NN` 非空、`IMM` 插入后不可修改、`GEN` 生成列、`PII` 个人信息、`SENSITIVE` 敏感数据。

### 1.1 公共字段组

| 字段组 | 字段 |
|---|---|
| `identity` | `id BIGINT UNSIGNED PK` |
| `created` | `created_at DATETIME(6) NN`、`created_by BIGINT UNSIGNED FK NULL` |
| `mutable` | `updated_at DATETIME(6) NN`、`updated_by BIGINT UNSIGNED FK NULL`、`row_version BIGINT UNSIGNED NN DEFAULT 1` |
| `archivable` | `archived_at DATETIME(6) NULL`、`archived_by BIGINT UNSIGNED FK NULL` |
| `retained` | `retention_class VARCHAR(32) NN`、`expires_at DATETIME(6) NULL` |

除非表中另有说明，业务聚合根使用 `identity + created + mutable + archivable`；不可变事实使用 `identity + created`；运行/事件明细使用 `identity + retained` 和自身时间字段。

### 1.2 通用枚举

| 枚举 | 值 |
|---|---|
| `record_status` | `draft`、`candidate`、`effective`、`superseded`、`archived` |
| `result_status` | `success`、`failed`、`partial`、`cancelled`、`blocked`、`expired` |
| `adoption_status` | `adopted`、`adopted_after_edit`、`rejected`、`not_reviewed` |
| `modification_intensity` | `none`、`minor`、`major` |
| `privacy_class` | `internal_id`、`pseudonymous`、`confidential`、`restricted` |
| `data_phase` | `mvp`、`sprint_6`、`future` |
| `quality_status` | `usable`、`warning`、`unusable`、`not_evaluated` |

## 13. 必须禁止的字段

- `api_key`、`access_token`、`refresh_token` 明文。
- 事件表中的完整文档正文、Prompt 全文、文件正文、未采用 AI 输出全文。
- 混合表达生命周期、工作流节点和最近模块的单一 `current_stage`。
- 含义不明的 `version`、`status` 或 `config_json`；必须有领域前缀或数据字典定义。
- 用 `is_current` 同时表达查看版本、工作版本、有效产物版本和当前配置版本。

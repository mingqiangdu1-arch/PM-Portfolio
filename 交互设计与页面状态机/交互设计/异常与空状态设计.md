# 异常与空状态设计

> 文档状态：当前有效
> 范围：用户可感知的加载、空数据、失败、权限、只读、冲突和恢复路径
> 边界：本文件不是正式页面状态机，不冻结状态码、事件或守卫条件

## 1. 状态设计原则

1. **保留用户投入**：网络、AI、解析或并发失败不得清空已输入内容。
2. **区分空与失败**：首次无数据、筛选无结果、无权限和加载失败使用不同说明与动作。
3. **局部失败局部处理**：次要卡片失败不阻断主任务；页面骨架和可用区域继续显示。
4. **说明影响范围**：明确哪些内容已保存、哪些未完成、业务状态是否变化。
5. **给出下一步**：每个异常至少提供重试、修改输入、返回安全位置、转人工或联系责任人之一。
6. **不制造假进度**：未知时长使用阶段式反馈；数据不足显示 N/A，不显示 0 或示例趋势。
7. **不泄露信息**：无权限时不展示敏感内容、来源摘要或对象存在性之外的过多细节。

## 2. 通用可感知状态

| 状态 | 页面表现 | 主要动作 | 次要动作 |
|---|---|---|---|
| 首次加载 | 保留页面骨架，关键内容使用占位 | 等待 | 超时后提供重试 |
| 局部刷新 | 保留旧内容并标记“正在更新” | 等待 | 取消筛选/刷新 |
| 首次空数据 | 解释该对象作用和创建条件 | 创建/导入 | 查看示例结构或返回 |
| 筛选无结果 | 保留筛选条件并说明无匹配 | 清除筛选 | 修改关键词 |
| 部分数据缺失 | 可用内容正常展示，缺失区单独说明 | 补充/重试该区 | 带风险继续（允许时） |
| 加载失败 | 保留页面框架和已知上下文 | 重试 | 返回所属列表/项目概览 |
| 保存失败 | 编辑内容保留在本地工作区 | 重试保存 | 复制内容/保存为本地草稿（若支持） |
| 无权限 | 显示所需身份和受限动作原因 | 联系负责人/申请权限 | 返回可访问页面 |
| 只读历史 | 持续显示历史版本和只读原因 | 返回工作版本 | 基于此版本派生（有权时） |
| 对象已归档 | 只读展示并标明归档时间/操作者 | 恢复（有权时） | 返回列表 |
| 对象不存在 | 不显示空白页 | 返回所属列表 | 打开项目概览 |
| 并发冲突 | 展示当前编辑与最新版本差异 | 基于最新合并 | 保存当前副本/放弃 |
| 会话失效 | 保存未提交编辑的临时副本 | 重新认证 | 复制内容后返回登录 |

## 3. 核心页面空状态矩阵

| 页面 | 首次空状态 | 筛选/局部空状态 | 推荐主动作 |
|---|---|---|---|
| PC-01 项目列表 | “还没有项目” | “没有匹配的项目” | 新建项目 / 清除筛选 |
| PC-03 项目概览 | 新项目显示启动方式选择 | 某类产物为空时显示其前置条件 | 从零开始或已有资料开始 |
| PC-04 资料导入 | 尚未上传资料 | 某类型未识别 | 上传资料 / 手动指定类型 |
| PC-06 版本管理 | 新项目只有 V1，不视为异常 | 比较条件不足 | 进入 V1 / 选择其他版本 |
| PD-01 Requirement | 尚无原始需求 | 无待确认问题 | 添加需求 / 进入 PRD（满足门禁时） |
| PD-03 PRD | 尚无 PRD | 当前筛选无历史版本 | 生成、上传或新建 PRD |
| PD-06 Flow | 尚未决定是否需要 Flow | 无子流程 | 生成/上传 Flow 或记录跳过原因 |
| PD-10 Review | 尚未发起评审 | 无待处理反馈 | 发起评审 / 查看全部反馈 |
| PD-13 Plan | 尚无评审通过的输入 | 无历史 Plan | 返回处理评审 / 创建 Plan |
| IC-01 实现确认 | 尚无确认轮次 | 当前轮次无差异 | 创建轮次 / 继续就绪检查 |
| PV-01 验证 | 尚未通过实现确认 | 无 Test Record | 返回完成确认 / 创建验证记录 |
| PV-04 Issue | 尚无 Issue | 筛选无结果 | 记录“无 Issue”结论或新建 Issue |

“无差异”“无 Issue”属于可提交的业务结论，不与尚未检查混为一谈。

## 4. AI 任务异常与恢复

### 4.1 生成前

| 问题 | 页面反馈 | 恢复路径 |
|---|---|---|
| 缺少必需上下文 | 列出缺失项及其用途，禁止开始 | 上传/关联资料、返回确认 Requirement |
| 缺少可选上下文 | 说明可能影响，允许有权用户继续 | 带风险继续或补充资料 |
| 来源版本已更新 | 显示原选择与最新版本 | 切换最新、保留原版本或取消 |
| 模型/连接不可用 | 不清空任务配置 | 选择可用连接（有权时）或联系管理员 |
| 无生成权限 | 保留只读配置摘要 | 联系产品负责人/管理员 |

### 4.2 生成中

| 状态 | 反馈 | 用户动作 |
|---|---|---|
| 排队/准备上下文 | 显示阶段和目标对象 | 离开页面、取消 |
| 长时间运行 | 显示仍在运行和最近更新时间，不伪造百分比 | 继续等待、取消、稍后查看 |
| 重试中 | 显示正在恢复及已发生重试，不暴露敏感供应商信息 | 等待或取消 |
| 用户取消 | 明确正式内容未改变 | 复制原配置重新运行或返回 |
| 会话断开 | 全局任务中心继续追踪服务端任务 | 重新连接并恢复任务详情 |

### 4.3 生成后

| 结果 | 反馈 | 恢复路径 |
|---|---|---|
| 格式/结构检查失败 | 指出不合格要求，候选不得直接正式保存 | 自动修复候选、重新生成、转人工编辑 |
| 重大错误 | 标记冲突来源或安全边界，禁用直接采用 | 修改候选、拒绝并记录原因、重新生成 |
| 部分结果 | 列出已完成与缺失部分 | 保留已生成部分并补充生成/转人工 |
| 任务失败/超时 | 保留输入、来源和追踪 ID | 重试、调整范围、切换可用配置、转人工 |
| 目标产物已变化 | 展示候选基于旧版本生成 | 与最新版本比较后合并或重新生成 |
| 保存候选失败 | 保留候选编辑内容 | 重试保存或复制内容，正式产物不变化 |

## 5. 文件上传与解析异常

| 异常 | 处理 |
|---|---|
| 上传中断 | 显示失败文件，不影响已成功文件；提供单文件重试 |
| 文件类型不支持 | 保留文件名和限制说明；允许更换文件，不创建虚假业务对象 |
| 文件过大 | 上传前尽早校验并说明限制与拆分建议 |
| 解析失败 | 保留原文件，标记“解析失败”；允许手动指定类型和关联对象 |
| 解析结果不确定 | 展示建议和依据，不自动确认；用户选择类型 |
| 同名文件 | 不静默覆盖；创建文件版本或要求用户明确关联方式 |
| 文件含敏感内容 | 阻止不合规处理并说明安全要求，不在错误日志展示内容 |

## 6. Review、修改、确认和版本保存异常

- **反馈定位失效**：产物已产生新版本时，反馈仍打开原冻结快照，并提供查看最新版本；不得把旧定位自动迁移到错误段落。
- **阻断反馈未处理**：“通过评审”不可用，页面列出阻断项并提供逐项跳转。
- **接受反馈后产生修改**：进入新草稿并保留反馈关联；退出前必须保存或放弃。
- **评审期间版本变化**：当前评审继续引用原版本；新版本必须显式发起新评审或记录无需重评依据。
- **确认轮次提交失败**：实际资料和差异草稿保留；旧有效轮次不变化。
- **已确认设计更新**：相关页面提示评审/确认需要重新处理，不把旧结论静默沿用。
- **版本保存冲突**：拒绝覆盖，显示最新版本创建人和时间，提供比较与合并。

## 7. 权限状态设计

### 7.1 动作权限矩阵（MVP）

| 动作 | 产品负责人 | 评审者 | 实现确认人 | 测试人员 | 平台管理者 |
|---|---|---|---|---|---|
| 创建项目/派生项目版本 | 允许 | 默认禁止 | 默认禁止 | 默认禁止 | 不因平台身份自动允许 |
| 编辑并保存正式产品产物 | 允许 | 默认只读 | 默认只读 | 默认只读 | 默认只读 |
| 提交评审反馈 | 允许 | 允许 | 可按参与身份 | 可按参与身份 | 按项目权限 |
| 确认评审通过 | 允许 | 默认禁止 | 默认禁止 | 默认禁止 | 按项目权限 |
| 提交实现资料/差异 | 允许 | 默认只读 | 允许 | 默认只读 | 按项目权限 |
| 使确认轮次生效 | 允许 | 默认禁止 | 可提交、默认不最终确认 | 默认禁止 | 按项目权限 |
| 创建 Test Record/Issue | 允许 | 可按参与身份 | 可按参与身份 | 允许 | 按项目权限 |
| 决定 Issue 去向/风险接受 | 允许 | 默认禁止 | 默认禁止 | 默认禁止 | 按项目权限 |
| 配置模型连接/系统开关 | 按系统权限 | 禁止 | 禁止 | 禁止 | 允许 |

该矩阵是交互默认，不替代未来细粒度 RBAC。具体授权可由同一用户兼任身份，但最终确认动作必须记录实际操作者。

### 7.2 权限页面表现

- 无查看权限：不渲染业务正文，只显示访问受限和返回入口。
- 有查看无编辑：页面完整只读，主操作替换为权限说明；不展示无意义的可点击禁用按钮堆。
- 有编辑无确认：允许保存草稿或提交，确认动作显示“等待产品负责人确认”。
- 权限在编辑中被撤销：保留本地未提交内容供复制，禁止继续写入并提示联系负责人。
- 跨项目来源无权：来源清单显示“不可访问来源”，不展示标题之外可能敏感的摘要。

## 8. 历史、归档和版本异常

- 历史 Project Version 默认只读，顶部持续显示当前查看版本与工作版本差异。
- 只读历史中的“编辑”替换为“基于此版本派生”；取消派生返回原历史位置。
- 项目归档不删除历史；有权用户可恢复，其他用户只读或返回列表。
- 来源产物被替代时，引用仍指向当时版本并显示“已有更新版本”。
- 回滚不提供“覆盖当前版本”，只提供“基于历史派生”。

## 9. 数据反馈异常

| 情况 | 展示规则 |
|---|---|
| 分母为 0 | 显示 `N/A` 并解释尚无符合条件样本 |
| 样本不足 | 显示分子、分母、样本量和“样本不足”，不显示改善结论 |
| 数据质量失败 | 指标卡显示不可用原因、受影响时间窗和最后可信数据 |
| 指标口径变化 | 显示 `metric_version` 和不可直接比较提示 |
| 多项同期变更 | 结论标记“组合变更/证据不足”，不归因给单项 |
| 部分指标加载失败 | 其他业务内容继续可用，失败卡片提供单独重试 |
| 无稳定基线 | 显示“基线采集中”，不套用外部 Benchmark 或示例目标 |

## 10. 文案结构

异常文案统一包含：

1. **发生了什么**：例如“候选结果保存失败”。
2. **影响了什么**：例如“你的编辑仍保留，正式 PRD 未变化”。
3. **为什么（可解释时）**：例如“目标 PRD 已创建新版本”。
4. **下一步**：例如“比较最新版本并合并”或“重试保存”。
5. **追踪信息**：仅在需要支持时提供可复制的任务/错误标识，不暴露敏感堆栈。

避免只写“操作失败”“没有权限”“数据为空”。

## 11. 后续状态机输入清单

页面状态机阶段至少需要为以下对象冻结状态、事件、守卫和转换：

- 页面数据加载与局部刷新。
- 编辑草稿、未保存修改、保存冲突和只读历史。
- AI Task/Call 的排队、运行、重试、成功、部分成功、失败、取消和过期。
- File Upload/Parse 的上传、解析、失败和人工确认。
- PRD/Flow/Plan 的草稿、评审、有效、被替代和归档。
- Design Review 与反馈处理。
- Confirmation Round 与验证就绪。
- Test Record、Issue 去向和项目版本生命周期。
- 权限授予、撤销、会话失效和对象归档。

# 交互设计与页面状态机阶段目录

本目录统一承载页面交互设计及其后续页面状态机阶段的正式成果，并通过子目录隔离两个阶段的主责文档。

## 目录规则

- `交互设计/`：保存用户任务、信息架构、页面结构、核心交互、AI 生成前/中/后交互、数据反馈、异常与权限路径、页面跳转关系等交互设计成果。
- `页面状态机/`：保存页面级状态定义、状态转换、触发条件、守卫条件、进入/退出动作及状态机校验成果。
- 跨阶段索引可以保存在本文件中；正式产出不得直接堆放在本目录根部。
- 两个阶段均以 `产品设计体系整理/` 的正式产品设计为上游依据，不得反向覆盖产品定位、业务边界或已确认规则。

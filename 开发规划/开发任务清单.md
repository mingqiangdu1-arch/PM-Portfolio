## 1. 使用规则

### 1.1 字段定义

| 字段 | 含义 |
|---|---|
| ID | 全局唯一任务编号；合并、拆分后不得复用旧 ID |
| Sprint | 计划交付 Sprint |
| 优先级 | P0 为 MVP/发布阻断；P1 为重要；P2 为增强 |
| 输入/依赖 | 必须已确认的文档、接口或前置任务 |
| 输出 | 可审查的代码、契约、迁移、测试或运行证据 |
| 验收证据 | 对应《验收标准》的自动化结果、截图、日志、查询或演示 |
| 降级 | 依赖失败时仍需保留的安全行为 |

### 1.2 完成定义

任务只有在代码、测试、契约/文档、事件/审计和异常路径同时完成后才可关闭。只完成前端静态页面、后端空接口、模拟成功数据或不可复现的人工演示均不算完成。

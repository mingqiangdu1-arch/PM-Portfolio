# Wireframe 与 UI 设计阶段目录

本目录是 Wireframe、视觉规范与高保真原型阶段正式成果的唯一保存位置。本阶段不得修改已经确认的产品逻辑、交互流程或页面状态机。

目录分工：

- `Wireframe/`：低保真页面、布局、信息层级和组件占位。
- `UI设计/`：`UI设计方案.md`、`设计系统规范.md`、颜色、字体、间距和 AI 状态视觉规范。
- `高保真原型/`：高保真页面、原型交互说明、Penpot/Figma 设计源记录、导出件及阶段验收记录。

页面状态机前置基线已于 2026-07-27 验收，低保真 Wireframe 与视觉方向也已确认。当前以 Penpot 作为主要可编辑设计工具；Phase 1 核心样板已升格为 V1 正式视觉基线，用户已于 2026-07-29 确认全量高保真原型人工验收通过。本阶段已经关闭，当前设计作为 Development Planning 与前端开发输入；Figma 路径暂停且不作为阶段阻塞依赖。

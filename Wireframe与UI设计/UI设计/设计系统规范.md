# 设计系统规范

> 文档状态：V1 正式设计系统基线；Penpot Phase 1 核心样板于 2026-07-28 通过人工验收  
> 建立日期：2026-07-27  
> 视觉方向：Light Trace Workspace；浅色、非蓝色、可替换 Token  
> 边界：定义设计 Token、样式、组件 API 和设计源结构，不定义前端实现或业务逻辑

## 1. Phase 0 发现结论

| 检查项 | 结果 | 处理 |
|---|---|---|
| 前端 Token/CSS/Tailwind | 未发现 | 以已确认 UI 方案建立 V1；WEB code syntax 使用拟定 CSS 变量名 |
| 前端组件库 | 未发现 | 设计源先建立最小组件 API；开发阶段再映射实现 |
| 品牌、Logo、视觉资产 | 未发现 | 不编造品牌图形；Cover 使用产品文字标识 |
| Figma 路径 | Starter 限额/权限路径暂停 | 未来仅在官方额度或权限恢复后同步核心展示页面，不作为当前阻塞依赖 |
| Penpot 设计源 | 官方 MCP 已连接并完成最小写入验证 | 作为当前主要可编辑设计工具，采用 Foundations / Components / Product UI 三 Pages 结构 |
| 既有设计库 | 无可继承产品库 | Phase 1 建立最小本地组件样板；开发阶段再做代码映射 |
| 正式设计依据 | 产品、交互、状态机、Wireframe 均已确认/形成 | 外部 Skill 不得覆盖这些基线 |

不存在“代码值与设计源值冲突”；当前没有可继承的视觉真值。浅色 V1 的具体色值可后续优化，但语义角色、变量名和组件属性在 V1 内保持稳定。

## 2. V1 文件结构

```text

  Actions / Inputs / Navigation / Feedback / Overlays / AI States / Review States / Version States
```

为兼容 Starter 三 Pages 限制，原计划的内容改用 Page 内 Board/Section 分区。Phase 1 只写入 Foundations、五类组件和一个核心页面样板；该样板已通过验收。用户于 2026-07-28 明确启动全量设计后，仍沿用三 Pages，通过 Board 分区扩展组件、页面、状态和原型。

## 3. Token 架构

| Collection | Mode | 内容 | 预计数量 |
|---|---|---|---:|
| Primitives | Value | Warm、Sage、Apricot、Success、Warning、Error、Info 原始值 | 36 |
| Semantic Light | Light | 背景、文字、图标、边框、动作和状态语义别名 | 30 |

### 3.4 Spacing, size and radius

| Group | Tokens |
|---|---|
| Spacing | `0=0`、`2xs=2`、`xs=4`、`sm=8`、`md=12`、`lg=16`、`xl=20`、`2xl=24`、`3xl=32`、`4xl=40`、`5xl=48`、`6xl=64` |
| Radius | `none=0`、`xs=4`、`sm=6`、`md=8`、`lg=12`、`xl=16`、`full=999` |
| Icon | `sm=16`、`md=20`、`lg=24` |
| Control height | `xs=32`、`sm=36`、`md=40`、`lg=44`、`xl=48` |
| Stroke | `hairline=1`、`strong=2` |
| Layout | `sidebar=216`、`right-panel=320`、`content-max=1440` |

Spacing/padding scopes 使用 `GAP`；Radius 使用 `CORNER_RADIUS`；尺寸使用 `WIDTH_HEIGHT`；Stroke 使用 `STROKE_FLOAT`。

## 4. Typography styles

写入设计源前先验证字体。目标字体为中文 `Noto Sans SC`、英文/数字 `Inter`；若中文字体不可用，必须停止并报告可用字体，不能静默换成 Inter。

| Style | Size/line | Weight | 用途 |
|---|---:|---|---|
| Display/Page | 28/36 | Semi Bold | 页面主标题/封面 |
| Heading/H1 | 24/32 | Semi Bold | 页面标题 |
| Heading/H2 | 20/28 | Semi Bold | 一级区块 |
| Heading/H3 | 16/24 | Semi Bold | 卡片/面板标题 |
| Body/Large | 16/24 | Regular | 强调正文 |
| Body/Medium | 14/22 | Regular | 默认正文 |
| Body/Small | 13/20 | Regular | 紧凑表格/辅助正文 |
| Label/Medium | 13/18 | Medium | 表单、按钮、标签 |
| Label/Small | 12/16 | Medium | Badge/Caption |
| Caption | 12/18 | Regular | 时间、来源、帮助文本 |
| Code/Small | 12/18 | Regular mono | ID、版本、追踪信息 |

## 5. Effect styles

| Style | 参数 | 用途 |
|---|---|---|
| Shadow/Subtle | `0 1 2 rgba(33,31,28,.06)` | 有必要的轻卡片层级 |
| Shadow/Overlay | `0 8 24 rgba(33,31,28,.14)` | Drawer、Popover |

### 6.2 Business patterns（高保真阶段）

- App Shell、Side Nav Item、Project/Version Context Bar。
- Stage Navigation、Next Step Card、Blocking Item。
- Workspace Header、Section Nav、Source/Check Panel、Diff Row。
- Review Feedback Item、Confirmation Difference Row、Test Step Row、Issue Disposition Panel。

业务 Pattern 只组合基础组件，不复制 Token 或创建相似但不同名的按钮/输入框。

## 7. Accessibility baseline

- 正文文字对比度至少 4.5:1；大文字至少 3:1。
- 主按钮 Sage/700 + White 对比度 7.08:1。
- AI 标签 Apricot/700 + Apricot/50 对比度 7.22:1。
- 主正文 Warm/900 + Warm/50 对比度 15.50:1。
- 次正文 Warm/700 + Warm/50 对比度 8.81:1。
- Error/600 + White 对比度 5.15:1。
- 焦点不只依赖颜色，使用 2px focus ring 和明确轮廓。
- 状态同时包含图标与文字；桌面控件高度不低于 32，触控场景不低于 44。

## 8. Phase 1 执行状态

### Existing

- 已确认：产品、交互、页面状态机、低保真布局和浅色视觉方向。
- 已可用：Penpot 官方 MCP 与已登录的可编辑设计文件。
- 已写入：98 个活动 Token、Foundations 三个规范 Board、五类组件样板和一个 1440 × 1024 核心页面样板。

### Missing

- 无代码 Token/组件可做一一映射。
- 无品牌 Logo 与图标库选择。
- Penpot 正式 SVG/PNG 自动导出因网络超时尚未完成。

### Resolution

- 当前 Penpot 文件继续保留；需在界面中人工重命名为 `AI 产品设计与验证平台 — Design System & UI`。
- V1 先验收 Foundations、五类组件和核心页面样板；验收后再扩全部基础组件家族与业务 Pattern。
- 色值通过变量集中管理，后续浅色方向优化不改组件属性或页面布局。

## 9. Phase 1 验收结果

用户于 2026-07-28 确认核心样板可升格为 V1 正式视觉基线，以下验收项通过：

1. 视觉方向、信息密度、组件风格和 AI 状态表达可作为 V1 正式样板。
2. 顶部段落级操作与底部整篇级操作层级清楚，`修改后采用` 是唯一主按钮。
3. Apricot、Amber、Red 三类语义可快速区分，右侧栏不会压过主对比区。
4. 双栏对比、当前任务提示和审核进度易读。

该确认只完成 Phase 1 样板验收，不等同于自动授权批量生成其余组件家族或全部高保真页面。后续页面必须沿用本基线，并在开始全量写入前获得明确执行指令。

## 10. 全量设计执行结果

用户于 2026-07-28 明确发出“开始全量设计”指令，现已完成以下候选交付：

- Foundations：4 个规范 Board，新增 Grid、Accessibility 与 Delivery 检查说明。
- Components：25 个展示 Board；16 个基础组件家族全部覆盖，并建立 14 个业务 Pattern。
- 本地组件库：30 个组件入口，其中 16 个基础组件、14 个业务 Pattern。
- Product UI：22 个 Board，包含 11 个高保真页面族模板、43/43 页面编号覆盖、3 组代表状态画廊、AI 前中后生命周期、全局任务中心与 T01～T07 原型入口。
- 原型：16 条 `click → navigate-to` 交互；Review 与 Implementation Confirmation 的阻断守卫保持禁用态，不绕过上游状态机。

本次全量扩展没有新增颜色角色、改变按钮主次层级或重定义页面状态。全量稿当前为阶段验收候选，验收前不升格为正式高保真基线。

# UI 设计方案

> 文档状态：V1 正式视觉基线（2026-07-28 已验收；色值允许后续通过 Token 优化）  
> 建立日期：2026-07-27  
> 边界：本文件只确定视觉语言与页面表现原则，不修改产品范围、交互流程、页面状态机或权限规则

## 1. 推荐视觉方向

方向名称：**轻盈可信工作台 / Light Trace Workspace**。

核心关键词：轻盈、可信、清晰、可追溯、专注、克制的智能感。

选择依据：平台承载长文档、版本、评审、差异、验证和 AI 候选，首要任务是让用户判断“当前事实、候选、风险和下一步”，不适合营销型大留白、强装饰渐变或聊天机器人式布局。

## 2. 已确认视觉决策

| 决策项 | 推荐方案 | 设计影响 |
|---|---|---|
| 页面密度 | 中高密度专业工作台 | 默认桌面可同时查看主内容、来源与状态；重要区块保留呼吸感 |
| 主色方向 | 浅暖中性色 + 柔和鼠尾草绿（Sage） | 避免常见蓝色后台观感；浅色表面为主，中等深度 Sage 只用于主操作和选中 |
| AI 强调色 | 浅杏色（Apricot）+ 明确 AI 图标/文字 | 只用于 AI 入口、运行和候选容器；不使用紫罗兰，也不表示正式成功 |
| 明暗模式 | Light 为本阶段完整基线；Dark 只建立 Token 基础，不制作全量页面 | 控制首阶段范围，保留后续扩展能力 |
| 圆角倾向 | 中等圆角 | 输入/按钮约 6～8，卡片约 8～12；保持工具感而非玩具感 |
| 卡片风格 | 细边框为主、阴影为辅 | 密集页面减少漂浮感；Modal/Drawer 才提高阴影层级 |
| 信息层级 | 标题—上下文—下一步—主内容—追溯 | 主推进动作稳定，辅助信息不争夺注意力 |
| 工作台结构 | 固定壳层 + 可折叠侧栏 + 三栏编辑模板 | 与已验收 Wireframe 和状态机一致 |
| AI 视觉表达 | AI Spark 图标 + Apricot 标签 + 候选容器 | 明确“AI 参与”和“候选”，不能让浅色底或装饰暗示已正式采用 |
| 状态表达 | 图标 + 文字标签 + 语义色 | 不以颜色作为唯一信息；失败/警告/成功不与 AI 色复用 |

用户已确认全部 V1 视觉决策；色彩采用浅色 V1，后续可在不改变语义角色和组件 API 的前提下优化具体色值。

### 2.1 浅色 V1 调色方向

| 角色 | 暂定方向 | 用途 |
|---|---|---|
| Canvas | 暖白/浅沙白 | 应用背景，降低纯白长时间阅读疲劳 |
| Surface | 白色/近白 | 卡片、编辑器、表格与弹层 |
| Primary | 鼠尾草绿 | 主操作、选中、焦点；必须满足文字和控件对比度 |
| AI Candidate | 浅杏色 | AI 入口、运行、候选容器背景，始终伴随 AI/候选文字 |
| Text | 暖黑/中性灰 | 正文、次要说明和禁用文本 |
| Semantic | 独立的成功、警告、失败、信息色 | 不复用 Primary 或 AI 色作为唯一语义 |

本阶段不使用蓝色作为品牌主色，也不使用紫罗兰作为 AI 默认识别色。

## 3. 视觉层级原则

1. 每页唯一主推进按钮使用 Primary；保存草稿、比较、查看来源使用 Secondary/Ghost。
2. 当前查看版本、工作版本、历史只读和候选身份在标题区持续显示。
3. 阻断项优先于一般提醒；重大错误可阻止采用，但不覆盖候选正文。
4. AI 运行中使用阶段轨迹和最近更新时间，不使用虚假进度百分比。
5. 表格、编辑器和 Diff 是高信息密度区域，装饰最少；提示和恢复动作靠近问题位置。
6. 危险/不可逆动作不使用主色，必须有明确文字和影响确认。

## 4. 字体方向

- 中文正文：优先 `Noto Sans SC`；若目标设计工具环境不可用，使用可验证的系统无衬线中文字体替代并记录。
- 英文、数字和代码：`Inter`。
- 正文强调可用字重而非彩色；长文档正文保持适合阅读的行高。
- 等宽内容仅用于 ID、版本号、追踪 ID、代码/结构表达，不用于普通正文。

正式字体必须在设计源写入前执行字体可用性检查；不可因工具可加载其他字体而静默替换。

## 5. 图标与插图方向

- 使用统一线性图标，常用尺寸 16/20/24 三档。
- 状态图标保持可识别：成功、警告、失败、信息、锁定、历史、AI 候选分别独立。
- 空状态使用简洁几何/线性插图或图标容器，不使用与业务无关的大型 AI 生成图片。
- 不把机器人头像作为 AI 的唯一表达，避免把工作台误导为聊天产品。

## 6. 动效边界

本阶段仅使用功能性过渡：Drawer/Modal 进入、Skeleton、Spinner、Toast、步骤状态切换和焦点反馈。暂不制作复杂时间轴、粒子、炫光或大范围页面转场。

## 7. 高保真执行策略

在视觉方向确认并建立最小设计系统后，先制作 **PD-03/PD-04 PRD 工作台 + AI 候选审核**。该样板一次验证：

- 全局壳层与项目/版本上下文；
- 三栏工作台；
- Button/Input/Tabs/Badge/Banner/Drawer；
- AI 配置、运行和候选身份；
- 差异、检查、未保存和保存状态；
- 右侧追溯抽屉与窄窗口收起规则。

该样板已于 2026-07-28 通过验收。用户随后明确发出“开始全量设计”指令，现已按同一视觉基线扩展 PC、PD、IC、PV、KC、SS 页面族，并补齐 Page States、AI 生命周期和 T01～T07 原型入口。全量稿采用“11 个页面族模板覆盖 43 个页面编号”的方式，不为 134 个状态复制 134 张近似整页。

## 8. 确认结论

用户已于 2026-07-27 确认页面密度、Light Mode、圆角、卡片、信息层级、工作台、字体、图标和动效方向，并要求取消蓝色主色与紫罗兰 AI 色，先采用浅色 V1。该方案现升级为设计系统输入；后续色值优化只修改 Token，不反向修改 Wireframe、交互或状态机。

全量高保真候选已于 2026-07-28 写入 Penpot，仍需用户完成阶段人工验收后，才能升格为正式高保真基线。

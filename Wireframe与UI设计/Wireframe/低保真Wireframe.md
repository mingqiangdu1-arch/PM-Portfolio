# 低保真 Wireframe

> 文档状态：Wireframe 已确认，作为设计系统与高保真输入  
> 阶段：Wireframe、视觉规范与高保真原型  
> 建立日期：2026-07-27  
> 目标平台：桌面 Web 优先  
> 保真度：低保真；只冻结布局、信息层级、组件结构和状态占位，不冻结颜色、字体、圆角、阴影或动效  
> 上游基线：当前有效产品设计、交互设计与 `页面状态机.md`

## 1. 目标与使用方式

本文件把 43 个信息架构页面归并为可复用的页面族模板，供设计系统、高保真原型和前端开发共同引用。页面编号不因模板复用而合并；状态、跳转和权限仍以上游主责文档为准。

设计原则：

1. 每页只有一个与“下一步卡片”一致的主推进动作。
2. 项目、查看版本和工作版本在项目内持续可见。
3. 历史、冻结、权限受限和 AI 候选必须持续可辨识。
4. 主内容优先；来源、追溯、检查和任务信息进入可展开侧区。
5. 页面级失败不清空全局壳层；局部失败不重置主任务。
6. 本文件展示的状态均来自已验收状态机，不为视觉完整性编造业务状态。

### 3.2 全局覆盖状态

| 状态 | 壳层保留 | 主内容区 | 首要恢复动作 |
|---|---|---|---|
| Bootstrapping | 顶栏、导航骨架 | 区块骨架 | 等待；超时后重试 |
| Project required | 一级导航 | 选择项目说明 | 选择项目 |
| Re-auth required | 原页面轮廓 | 认证覆盖层，说明未提交内容 | 重新认证 |
| Access denied | 安全导航 | 不渲染业务正文 | 返回项目列表/联系负责人 |
| Read only | 完整正文 | 顶部持续原因条，编辑动作替换 | 返回工作版本/派生 |
| Not found | 导航与已知上下文 | 对象类型、可能原因 | 返回所属列表 |
| Archived | 完整归档详情 | 归档标识和恢复资格 | 恢复/返回列表 |
| Partial failure | 正常主内容 | 失败卡片原位重试 | 重试局部区域 |

### 8.2 工作台状态占位

| 状态 | 主区表达 | 操作变化 |
|---|---|---|
| No artifact | 创建方式与前置条件 | 生成/上传/新建 |
| Loading | 三栏稳定骨架 | 保留返回与上下文 |
| Editing dirty | 标题区显示“未保存” | 离开触发保存/放弃/留在 |
| Saving | 仅保存范围锁定 | 禁止重复提交 |
| Save failed | 输入保留、错误定位 | 重试/复制内容 |
| Candidate review | 双栏差异 | 审核后才允许采用 |
| Adoption blocked | 候选仍可读 | 修复来源/质量/权限 |
| Frozen/history | 正文完整只读 | 比较/基于此新建 |
| Version conflict | 当前副本与最新版本并列 | 比较/合并/保存副本 |

## 14. WF-10 系统必要设置

### 14.1 SS-02 用户偏好

左侧为设置分类，右侧为语言、默认项目视图、通知偏好等已确认基础配置。保存成功/失败在配置区反馈，不让用户误认为业务对象被修改。

显示连接名称、供应商、可用状态、最近检查和权限说明；密钥只允许受权用户编辑，读取时不回显完整值。连接测试是局部异步状态，不改变其他设置。

## 16. 响应式与窗口行为

| 范围 | 布局策略 | 关键变化 |
|---|---|---|
| ≥ 1280 | 标准桌面工作台 | 固定侧栏；工作台三栏；右侧检查区可见 |
| 1024～1279 | 紧凑桌面 | 侧栏可收起；右侧检查区变抽屉；表格隐藏次要列 |
| 768～1023 | 平板/窄窗口 | 单主栏；章节导航与检查区均为抽屉；阶段导航横向滚动并有文字标签 |
| < 768 | 只读/轻操作优先 | 卡片化列表；复杂 Diff、谱系和长表单提示切换桌面；不删除核心恢复动作 |

复杂编辑与版本比较以桌面为完整能力目标。移动端若不支持某项复杂操作，必须展示原因和返回/稍后处理路径，不能呈现无响应控件。触控目标不小于 44×44；键盘焦点顺序与视觉层级一致。

## 17. 状态界面最小验收集

高保真阶段至少为以下组合建立代表界面，而不是为 134 个状态逐一复制整页：

1. PC-01：Ready、First Empty、Filtered Empty、Load Failed。
2. PC-03：Working Ready、Working Blocked、History Read Only、Partial Failure。
3. 通用工作台：No Artifact、Editing Dirty、Candidate Review、Save Failed、Frozen History、Version Conflict。
4. AI：Configuring、Generating、Result Ready、Quality Blocked、Failed、Stale Target。
5. Flow：Text Review、Mermaid Review、Validation Failed、Effective。
6. Review：Open、Blockers Pending、Ready for Decision、Superseded Context。
7. Confirmation：Evidence Pending、Difference Review、Ready to Confirm、Confirm Failed、Confirmed History。
8. Validation：No Record、Editing、Submitted Read Only、Issue Disposition、Save Failed。
9. Global：Re-auth、Access Denied、Read Only、Not Found、Archived。

## 18. Wireframe 验收结论

本候选保持 43 个页面编号不变，并以 11 个复用模板覆盖当前 MVP 与可选 Flow 页面。页面目标、信息区域、主要/次要动作、核心组件、异常/权限状态和响应式行为均有明确位置。视觉方向确认后，可据此建立最小设计系统并先生成一个核心工作台样板。
